# AI Prompts｜AI 学习提示词

> Reusable AI study prompts developed from personal practice, with clear limits on what each platform can actually do.  
> 基于个人学习实践整理的通用 AI 提示词，优先保证实用性、可迁移性与功能描述准确。

## Available prompts｜已收录提示词

| Prompt | Purpose / 用途 | Platform |
| --- | --- | --- |
| [AI IELTS Speaking Coach & Examiner](ielts-speaking-coach.md) | Guided Speaking practice, mock tests, feedback and revision / 雅思口语陪练、模拟考试、纠错与复习 | Voice-capable AI assistants; limited text-only use |

## Quick start｜使用方法

1. Open [the IELTS Speaking prompt](ielts-speaking-coach.md) and copy the **entire text inside “Copy-paste prompt”** (including its instructions, excluding the surrounding Markdown fence). / 打开提示词页面，复制“Copy-paste prompt”代码块中的完整英文指令。
2. Paste it into a fresh conversation in an AI assistant that supports voice chat; start voice mode if available. / 在支持语音聊天的 AI 工具中新建会话、粘贴提示词，建议启用语音模式。
3. Choose **Coach Mode** for guided practice or **Examiner Mode** for a mock interview. / 选择陪练模式或模拟考官模式。
4. Change part, difficulty, correction intensity or explanation language with a short command at any time. / 可以随时切换练习部分、难度、纠错强度与讲解语言。

**Example commands｜示例指令**

- `Coach mode. Part 1. Intermediate level. Standard corrections. English only.`
- `Examiner mode. Please conduct a full mock Speaking test.`
- `Switch to native-like corrections. Explain the nuances in Chinese.`
- `End session. Summarise my repeated errors and give me review homework.`

## Modes and settings｜功能配置

| Setting | Options |
| --- | --- |
| Mode｜模式 | Coach / Examiner |
| Sections｜考试部分 | Part 1 / Part 2 / Part 3 / Mixed |
| Correction｜纠错强度 | Relaxed / Standard / Strict / Native-like |
| Difficulty｜学习难度 | Foundation / Elementary / Intermediate / Advanced |
| Language｜讲解语言 | English / Bilingual / Chinese |

**Coach Mode｜口语老师**：逐题练习 → 基于实际回答纠错及自然表达优化 → 重答同一道题 → 课后总结与复习建议。鼓励学习者在实时语音课中承担主要说话时间。

**Examiner Mode｜模拟考官**：尽量贴近 11–14 分钟、Part 1–3 的完整结构；考试过程中不提供教学反馈，结束后根据可观察到的证据作分析。

## Platform compatibility｜跨平台说明

This prompt is **not tied to Doubao**. It may be used with ChatGPT, Gemini, Doubao or other assistants *if their chat interfaces accept custom instructions*. Specific voice, search, memory and automation features depend on the service and plan. No platform has been independently certified as fully compatible with every function here.

这是一份**平台无关的通用提示词**，不是某个平台的专用插件。支持文本输入不代表支持真实语音评分；语音转写也不等同于能直接评估发音。

| Capability | Requirement / Limitation |
| --- | --- |
| Conversation practice | Text or voice chat; **voice preferred** |
| Pronunciation assessment | Actual accessible speech audio, not text transcription alone |
| Full band estimate | Sufficient speech evidence across all four scoring criteria; always unofficial |
| “Current-season” questions | Independently accessible and verified sources; otherwise use clearly labelled practice questions |
| Accurate timing | Reliable timer or an external clock; otherwise timing is approximate |
| Three-hour reminders | A supported authorised reminder/calendar tool and the learner's consent; otherwise manual reminder instructions |

**Privacy｜隐私：** Avoid pasting ID numbers, score reports containing private identifiers, personal recordings or sensitive details into public prompts or issues. Review the chosen platform's data settings before sharing audio.
