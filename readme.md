## 🧭 如何使用

- **想看真实经历**：从“个人备考经验”进入；其中未整理完的部分会明确标记。
- **想找老师或网站**：直接打开“学习资源推荐”；资源按科目分类，状态分为“自己提及 / 已体验 / 待核实”。
- **想确认考试规则**：以“考试信息”所列官方入口为准，不用旧经验替代最新政策。

## 🔄 更新与维护

本项目采用纯 Markdown + GitHub 相对链接，不依赖网站框架，手机和电脑都能直接阅读。内容按主题分文件，未来可以逐步增加真实案例、练习复盘和资源核对结果。

- 内容建议与纠错：[贡献与维护指南](CONTRIBUTING.md)
- 更新资源时注明是否亲自体验，以及链接或信息是否已核实。
- 尽量通过小型 Pull Request 更新，不一次性重构全部内容。
- 个人考试资料、成绩等仅在适合公开时才补充。

> **声明**：这是个人学习档案，不是官方考试指导，也不承诺提分或押中原题。第三方资源仅供参考，其有效性与收费情况可能变化。
