# 雅思备考方法笔记｜听力、阅读与写作

之前收藏过一些考生的经验分享，其中有不少值得反复参考的细节。我把它们按科目整理在这里，方便需要时快速找到具体的练习方法。

## 阅读 Reading

### 从识别词汇开始

有一份经验提到，阅读初期不必急着追求庞大的词汇量，可以先把常用词练到**看见就能迅速反应出意思**。

- 用 Excel 筛选高考 3500 词表里已经熟悉的单词，留下需要反复复习的部分。
- 用不同颜色标记熟悉程度，每天集中巩固反应慢的词。
- 背词的目标先放在**看懂文章和快速识别词义**，再逐步补充复杂表达。
- 遇到不认识的词，不必立即停下：先观察上下文、转折词、否定关系和作者态度，看是否仍能判断句意。

这不是说词汇量不重要，而是提醒自己：**理解句子与文章逻辑，同样是阅读能力的一部分。**

### 限时训练与时间分配

我很喜欢这份经验里关于 Passage 1（P1）的建议：把 P1 当作可以重点突破的提速环节。

- 先尝试每篇 **15 分钟内**完成；基础不同，起始目标也可以调整。
- 重点找话题词、定位线索、答案句，减少不必要的逐句细读。
- 遇到暂时无法判断的题，先标记并继续，不让一道题拖累后面所有题目。
- 集中完成一轮训练后，再安排一段时间专项复盘。
- 速度提升以后，继续检验准确率，而不只是追求更短耗时。

原经验分享中也提到过将 P1 缩短到约 12 分钟的练习结果。对我而言，更值得借鉴的是这种**限时、专注、果断**的训练方式，而不是把某个分钟数当成所有人的统一标准。

### 错题复盘：先弄清楚为什么错

阅读复盘可以先聚焦错题，不必把整篇文章重新精读一遍。最值得记录的是错误原因。

| 错因 | 复盘时要问的问题 | 下一步 |
| --- | --- | --- |
| 同义替换 | 题干和原文的表达为什么没对应上？ | 整理关键词与原文对应说法 |
| 词汇 | 哪个词影响理解？ | 结合上下文记录词义与搭配 |
| 长难句 | 有没有看错修饰关系、否定或转折？ | 划出主干和逻辑连接 |
| 定位 | 答案其实在哪里？为什么没找到？ | 标记定位线索 |
| 时间分配 | 是否在难题上纠结太久？ | 记录耗时，重新限时练习 |

那份经验中还提到用 Excel 复盘同义替换与长难句。我觉得很适合将这些错因整理成一个可筛选的表格，定期看哪些问题反复出现。

### 收藏的阅读资源线索

- **ZYZ**：阅读题目练习与重复刷题。
- **奶爸**：阅读方法课程。
- **大国王老师**：考场心态与做题策略，原笔记提过一节与 P3 心态有关的免费课程。

这些名称沿用收藏笔记中的称呼。选资源时，还是以能否解决自己当前的问题为准，不需要把所有课程都看一遍。

## 听力 Listening

### 辨音、词义、拼写放在一起训练

有一位分享者用“爱听写”复习常用词，重点不是默背拼写，而是让几个动作联动起来：

- **眼睛看**：确认单词含义与拼写。
- **嘴巴读**：把看到的词与实际发音联系起来。
- **手上写**：检验能不能准确拼出。
- **耳朵听**：反复确认自己能不能在语流中认出这个词。

如果单词认识却听不出来，就优先练声音与词义的对应，而不只是继续扩大词表。

### Part 1 / Part 4：错句精听与预判

收藏的经验中，有人专门集中训练 Part 1 和 Part 4，并在复盘时主要回听错题对应的句子。

可以试试这个顺序：

1. 做题前先看题目，划出关键词。
2. 尝试预判填空需要的**答案类型**，例如地点、数字、名词或描述。
3. 正常完成听力题目。
4. 回听做错或没把握的片段，找到实际答案与题干的对应关系。
5. 再用完整套题练习各部分的衔接与时间节奏。

听力中反复出现的**同义替换、转折词、连读和弱读**，可以单独记录，不必每次都从头听到尾。

### Excel 三个 Sheet 的复盘方法

这是我想重点保留的一套整理思路。原经验提到三个 Sheet，下面按实际使用场景补充了适合记录的字段。

| Sheet | 用途 | 可记录内容 |
| --- | --- | --- |
| **同义替换** | 识别题干和音频用词的不同 | 题干表达、音频表达、语义关系、来源 |
| **转折词** | 捕捉答案方向的变化 | 转折信号、前后信息、误判原因 |
| **连读与弱读** | 改善听辨 | 原句、听错的词、语音现象、复听结果 |

复盘时不用追求表格做得多漂亮。只要每次能留下**一条以后复听有用的记录**，就有积累价值。

### 听力考试中的心态

原分享特别强调：正式播放时，一旦漏听某题，不要还在回想它而忽略下一道题。

另外，考前可以练习题目预判和草稿记录习惯，减少考试时慌乱。至于笔记多少、精听频率以及是否需要大量听抄，都应该根据自己的听辨问题调整。

收藏笔记还提到“大胡子老师 / 大老师”的**填空预判**和**地图匹配**讲解，以及“大国王老师”的技巧课程。具体课程入口以后有可靠链接再补。

## 写作 Writing

写作部分的收藏经验相对简短，不过有三个提醒很实用。

### 先保证写得完

写作练习除了积累语言，还应当定期在规定时间内完成 Task 1 和 Task 2。能不能按时写完、是否回应全部要求，是复盘时必须检查的事情。

### 优先减少偏题和明显错误

练习时可以按以下顺序自查：

1. 是否真正回答了题目？
2. 文章结构是否清楚，段落之间是否连贯？
3. 举例有没有支持论点？
4. 常见语法错误是否反复出现？
5. 最后有没有留出一点时间检查？

这几项只是基础检查，不能直接推算雅思写作分数；真正评分还要结合官方四项标准。

### 找到适合自己的方法，坚持练下去

不同老师的讲解和模板可以作参考，但并不是收藏越多就学得越好。选定一种适合自己的训练方式，结合反馈反复修改，比不停更换方法更有意义。

同时也要照顾好作息和考试状态，避免练习时能写、到考场却因为节奏失控写不完。

## 我会如何使用这些笔记

把上面的建议整理成一个简单的练习循环：

**限时做题 → 记录错题 → 找到具体错因 → 针对性练习 → 再次检验。**

每次复盘可以只问自己三个问题：

1. 这次主要错在哪里？
2. 我准备做什么来解决这个问题？
3. 下一次练习怎么判断自己真的进步了？

题量和学习时长不必照搬别人的计划。最有价值的是能够持续发现问题、解决问题。
